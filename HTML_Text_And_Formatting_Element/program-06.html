My Programming Notes

JavaScript

JavaScript is a programming language mainly used to make web pages interactive and dynamic. It can be used to create buttons, forms, animations, calculations, and many other features on websites. JavaScript is widely used for web development.

Beginner Example 

let name = "Manmeet";
console.log("Hello " + name);

Java

Java is a popular programming language used for developing applications, web applications, enterprise software, and Android applications. It is known for being reliable and portable. Object Oriented Programming is an important concept in Java.

Beginner Example 

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Python

Python is a simple and powerful programming language used for web development, data science, artificial intelligence, automation, and many other applications. Python is popular because its syntax is easy to understand.

Beginner Example 

name = "Manmeet"

print("Hello " + name)
